# Official standard: selective lookup

Authority: **ASD-STE100, Issue 9, 2025-01-15**.

- [Official downloads](https://www.asd-ste100.org/STE_downloads.html)
- [Official Issue 9 PDF](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf)

The official text and its dictionary control a strict review.
This map is a set of lookup targets, not reproduced rule text, a full rule catalog, or a dictionary.
Verify each target in the official issue before citing it as evidence.
Do not substitute a search snippet or this skill for the primary text.

## Read only what the question needs

| Question | Selective lookup |
|---|---|
| Does a replacement change meaning? | Rule 9.1 and its explanation: preserve meaning and restructure when a direct replacement is insufficient |
| Is this word valid here? | Writing rules, Section 1, and the specific dictionary entry: part of speech, meaning, forms, and alternatives |
| Is a domain verb, including “delete”, eligible? | Rule 1.12, its restrictions, and the relevant dictionary entry; assess approved alternatives for the same operation |
| Can an established technical name be longer? | Rules 2.1 and 2.2: multi-word nouns and the longer-name exception |
| Can this modal or verb form express the same intent? | Section 3, especially Rules 3.2–3.5, and the relevant dictionary entry |
| Does a reader instruction have a condition or multiple actions? | Rules 5.1–5.4, including the simultaneous-action exception in 5.2 |
| What limit applies to a description or note? | Rule 5.5 and Section 6, including sentence limit 6.3 |
| How do parentheses and special units count? | Rules 8.5 and 8.6: outer and inner counts; verify special categories, not generic-name shortcuts |
| Is a warning or a punctuation change appropriate? | Relevant portions of Sections 7 and 8 |
| Is this a requirement or a recommendation? | Section 9: writing practices and separately labeled general recommendations, including GR-6 |

Numbered sections in this table refer to the writing rules, not dictionary locations.
Find dictionary entries by word in the official dictionary.
Follow the official document's headings, not an assumed page number.

## Missing source or limited scope

If the primary text or dictionary is unavailable, do not guess rule IDs or approved vocabulary.
Give a bounded clarity review and identify strict items that remain unverified.
If only selected passages or entries were reviewed, describe that scope explicitly.
Official requirements are not GR recommendations; neither is a chat adaptation from this skill.
A few sentence checks do not establish a full audit or compliance.
