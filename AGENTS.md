Keep this a portable Markdown skill, not a bundle, service, or standard mirror.
Before changing guidance, read `skills/simple-english/SKILL.md` and the relevant references.

These are static guards, not behavioral tests or proof of STE compliance.

Test changed guidance against the synthetic fixtures in a cold model session; report actual behavior separately.
